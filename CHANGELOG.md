# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-02-24

### Added
- CSS design tokens: colors, typography, spacing, shadows, borders, transitions, z-index (`styles/tokens.css`)
- Component styles: buttons, cards, navigation, typography, badges, dividers, containers, grids, forms (`styles/components.css`)
- Animation utilities: keyframes + utility classes + duration/delay modifiers (`styles/animations.css`)
- Utility class library: display, flex, gap, spacing, text, font, color, border, sizing, position, overflow, opacity, cursor, transitions, accessibility (`styles/utilities.css`)
- Entry point that imports all modules (`styles/index.css`)
